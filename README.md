# Dragon Stüdyo

Minimal Next.js (App Router) starter for Dragon Studio.

## Kalıcı adresler

| Sayfa | URL |
|-------|-----|
| Ana sayfa | https://dragon-studyo.vercel.app |
| Stüdyo sihirbazı | https://dragon-studyo.vercel.app/studio |

## Geliştirme

```bash
npm install
npm run dev
```

Production build: `npm run build` then `npm start`.
